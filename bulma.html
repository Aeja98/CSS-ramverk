Bulma

Bulma är ett modernt CSS-ramverk som gör det enkelt att skapa responsiva och stilrena webbplatser. Ramverket bygger på flexbox och använder färdiga CSS-klasser för att skapa olika layouter och komponenter.

Bulmas webbplats

Om Bulma

Bulma är ett kostnadsfritt CSS-ramverk med öppen källkod som används för att utveckla responsiva webbplatser. Det innehåller färdiga klasser för bland annat knappar, navigering, formulär, tabeller och layouter.

Ramverket bygger på Flexbox, vilket gör det möjligt att skapa flexibla layouter som anpassar sig efter olika skärmstorlekar. En skillnad jämfört med vissa andra ramverk är att Bulma fokuserar på CSS och inte kräver JavaScript för sina grundläggande komponenter.

Utvärdering

Fördelar

  • Enkelt och tydligt klassnamnssystem.
  • Bygger på Flexbox och ger flexibla layouter.
  • Responsiv design utan behov av många egna media queries.
  • Färdiga komponenter som går att anpassa med egen CSS.
  • Kräver inte JavaScript för grundläggande styling.

Nackdelar

  • Har ett mindre ekosystem än Bootstrap.
  • Innehåller färre färdiga komponenter.
  • Vissa mer avancerade funktioner måste byggas själv.
  • Kan kräva extra CSS för mer specifika designer.

Mina erfarenheter

Jag tyckte att Bulma var relativt enkelt att komma igång med eftersom många klassnamn var tydliga och några funktioner liknade dem i Bootstrap. Dokumentationen var också lätt att förstå och hitta i, så jag använde framför allt Bulmas dokumentation som hjälp under arbetet. Jag uppskattade särskilt att responsiviteten till stor del sköttes automatiskt genom ramverkets färdiga layoutsystem. Jag behövde bara skriva egen CSS för navigeringen och sidfoten för att få dem att passa ihop med resten av webbplatsen.
