Bootstrap

Bootstrap är ett populärt CSS-ramverk som gör det enklare att skapa responsiva och användarvänliga webbplatser. Ramverket innehåller färdiga komponenter och ett flexibelt rutnätssystem.

Bootstraps webbplats

Om Bootstrap

Bootstrap är ett kostnadsfritt ramverk med öppen källkod som används för att utveckla responsiva webbplatser. Det innehåller färdiga CSS-klasser för bland annat knappar, navigering, formulär, tabeller och layouter.

En av Bootstraps främsta funktioner är dess rutnätssystem (grid system), som gör det möjligt att skapa layouter som anpassar sig efter olika skärmstorlekar. Ramverket kan även kombineras med JavaScript för att skapa mer interaktiva komponenter.

Utvärdering

Fördelar

  • Stort utbud av färdiga komponenter.
  • Enkelt att skapa responsiva layouter.
  • Användbart och flexibelt grid-system.
  • Minskar behovet av egen CSS.
  • Omfattande dokumentation och många exempel.

Nackdelar

  • Kan vara svårt att lära sig i början.
  • Många CSS-klasser kan göra HTML-koden omfattande.
  • Webbplatser kan lätt få ett liknande utseende.
  • Egna designändringar kan kräva extra CSS.

Mina erfarenheter

Jag tyckte att Bootstrap var ganska svårt att förstå i början eftersom många klasser och funktioner var nya för mig. Jag använde framför allt Bootstrap CheatSheet för att förstå vad de olika klasserna gjorde. När jag väl kom in i arbetssättet gick utvecklingen snabbare. Jag behövde bara skriva lite egen CSS för navigeringen och sidfoten, medan ramverkets färdiga komponenter och grid-system gjorde resten av arbetet enklare. Jag uppskattade särskilt att responsiviteten till stor del redan var inbyggd.
